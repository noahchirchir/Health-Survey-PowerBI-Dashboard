# Health Survey Dashboard Using PowerBI

## Introduction

The Health Survey Dashboard is an interactive data visualization tool built using Power BI to analyze and present key health metrics from a population dataset. It provides insights into average age, weight, height, and BMI distribution across genders and BMI categories. Designed for healthcare analysts and professionals, this dashboard supports better understanding of health trends to inform policy and resource planning.

# Features

#### Interactive KPIs

Average Age, Weight, Height, and BMI dynamically calculated using DAX

Total Surveyed Individuals summarized for quick reference


#### Data Visualizations

Pie Chart: Gender distribution

Bar Chart: Average BMI across BMI categories

Scatter Plot: Correlation between weight and height segmented by gender

Line Chart: BMI trends across birth years

Summary Table: Gender-wise health metrics


#### Slicer Filters

Filter dashboard by Gender and BMI Category for comparative analysis


#### Clean Data Modeling

Structured and efficient data model built using Power Query and DAX

Seamless handling of raw Excel data


#### User-Friendly Design

Visually intuitive layout for analysts and non-technical users




# Key Insights

Males exhibit higher average weight and BMI compared to females.


Most respondents fall within the healthy or overweight categories.


BMI distribution reveals noticeable trends across generations.


A strong correlation exists between height and weight, observable by gender.
